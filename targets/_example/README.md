# Example Target: Acme Corp Design System

This is an **illustrative example** showing the expected file structure for a target system. It uses a fictional "Acme Corp Design System" to demonstrate naming conventions, manifest format, and token structure.

**To start a real target:** Copy the files from `templates/` into `targets/{your-target}/` and follow the skills starting with `skills/01-survey-target-system.md`.

## Files

- `manifest.yaml` — Example manifest with 3 components spanning different mapping types
- `sources.md` — Example sources inventory showing what a complete sources doc looks like
- `tokens/theme.css` — Example token mapping showing the `--{target}-*` naming convention
